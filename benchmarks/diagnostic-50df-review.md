## 确认并修复的问题

| 问题 | 原版行为 | 0.1.184 行为与验证 |
| --- | --- | --- |
| 子线程异步委派异常 | `routeChildNotification`、`discoverChildren` 后继回调失败只提示页面并保留 busy，挂起 RPC 仍等超时 | 接入 `handlerFailed`：安全落盘、结束阶段、关闭半更新连接并释放请求；两种回调注入均检出，保持用户配置、不重放任务 |
| 提问状态清理异常 | `finish` 捕获后只提示页面，无持久诊断记录 | `question.cleanup` 保留标准错误码和进程关联，正常结束本轮；清理条件修正后可再次正常收尾 |
| 历史分页不完整校验 | 重复轮次 ID、legacy 轮次缺少 items 可以进入缓存 | 全部分页校验后才替换缓存；失败保留上次历史，后续成功绑定原失败；不把其他线程或较早并发成功当作恢复 |
| 压缩 WebSocket 发送异常 | 排队发送与反向发送部分同步/回调失败只断开，待压缩结果缺少明确失败原因 | `compaction.websocket.write` 固定原因和连接 ID，待完成压缩终结为 failed，释放两端；四种发送故障注入验证真落盘和扫描检出，取消保持 cancelled |
| 手机桥接断连归因不足 | 只有 disconnected/recovered，容易误读为 Codex 进程异常 | 固定 `connectionKind=remote_bridge`，记录关闭来源、原因、未决数、重连安排；恢复关联上次 failureId/connectionId；主动退出是 cancelled |

| 快照文件瞬时消失 | 目录扫描后、打开前消失的已有文件未登记，重现后可能被当作新增删除 | 标为 unreadable/unrestorable，不能用于删除式还原；变化、增长、符号链接的原安全校验保留 |
| 诊断来源与统计 | 混合版本失败 ID 可能被并为同链；后端/SSE/技能安装易归入插件运行 | 唯一链按版本、窗口和进程隔离；明确区分工具、手机桥接、后端服务、CLI 组件；恢复记录携带失败/成功日志位置供报告与模型摘要引用 |
| RPC 超时细节 | 缺少阈值和结束来源 | 记录 timeoutMs、terminationReason，区分本地超时与传输/后端拒绝；未改原预算 |
