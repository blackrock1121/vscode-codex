# 功能迁移记录

## 已确认范围

保留原项目除 QQ、SLS 外的功能。主动模型缓存预热不启用；正常 Codex 缓存由运行时管理，只保留连接预启动。

## 模块

- `src/codex/rpc.ts`：stdio JSONL、握手、请求关联、超时、退出回收、CLI 路径定位。
- `src/codex/process.ts`：每会话独立进程、线程启动／恢复、轮次、审批、问题、事件映射。
- `src/codex/session.ts`：官方会话接口、分页历史、改名、删除与派生。
- `src/snapshot.ts`：回合开始前的文本基线、回合结束时检测创建／修改／删除。
- `src/checkpoints.ts`：快照持久化、还原点和文件回滚。
- `src/panel/chatViewProvider.ts`：VS Code 面板、命令、连接池、通知、更新和原生 diff。
- `src/webview/main.ts`、`media/main.css`：沿用并适配原项目界面。

## 有意保留的差异

- 模型和推理档位由 Codex 提供，移除 Claude 家族模型名与 Auto 权限模式。
- Codex 只读沙箱不等同于 Claude 的 plan 协议。
- 自动保存放在轮次发送前，Codex 通知不具备 Claude PreToolUse 阻塞 hook 的同等保证。
- 回退创建官方历史分支并归档旧记录；不直接截断原记录。
- 文件基线有大小与目录限制，未覆盖内容不宣称可恢复。
- 额度读取不发送 `/usage` 模型请求；未知上下文容量不硬编码。
- 原项目没有行内补全，新插件也未新增行内补全。

## 验证范围

以测试命令输出为准。真实账号测试仅操作临时目录、专用测试会话；不连接 webhook、不修改用户已有会话。VS Code 实际界面的主题、拖拽、跨面板快捷键以及真实 webhook 和升级安装，仍需在安装后的环境验收。
